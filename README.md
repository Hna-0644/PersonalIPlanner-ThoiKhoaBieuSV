# PersonalPlanner
## Website quản lý thời khóa biểu và kế hoạch cá nhân tích hợp sắp xếp lịch trình tự động

### 1. Thông tin dự án
Đề tài: Thiết kế và xây dựng website quản lý thời khóa biểu
và kế hoạch cá nhân tích hợp sắp xếp lịch trình tự động.

### 3. Chức năng dự kiến
- Quản lý thời khóa biểu.
- Quản lý kế hoạch và công việc cá nhân.
- Nhắc lịch tự động.
- Thống kê công việc và lịch sắp tới.
- Quản lý tài khoản người dùng.

### 4. Công nghệ dự kiến
- Frontend: HTML, CSS, JavaScript.
- Backend: Node.js, Express.js.
- Database: MySQL.
- Quản lý mã nguồn: Git và GitHub.

### 5. Cấu trúc thư mục
- frontend/: giao diện website.
- backend/: máy chủ và API.
- docs/: tài liệu dự án.
- tests/: kiểm thử.
